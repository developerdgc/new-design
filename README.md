# Limos 4 Less — Homepage Redesign

A simpler homepage for [limos4less.com](https://limos4less.com/). All text, images, and links come from the current website.

**Open `index.html` in a browser to view it.** Screenshots are in `preview/`.

## What changed

| Current homepage | New homepage |
|---|---|
| 14 sections, ~14,800px long on mobile | 11 short sections, ~9,500px on mobile |
| Services (3 cards) + Occasions (6 cards) repeat each other | One "What we do" section with 4 cards |
| "Get Instant Rates" button opens a phone call | Buttons say what they do: "Book Online" / "Call 410-737-7600" |
| Online vs. phone booking rule hidden in FAQ page | Shown in the hero: "Riding today? Please call." |
| No "how it works" | 3 steps: book → fixed quote → chauffeur arrives |
| Sedan/SUV capacity hidden in a small card | "Choose your car" section with passengers and bags |
| Areas served only in an FAQ answer | "Areas we serve" list |
| Long paragraphs in About / Why Us | Short points and stats |
| 10 menu items + Log In button | 5 menu items + Call + Book a Ride |

## Sections

1. Header (sticky)
2. Hero + Trustpilot rating
3. Trusted by (client logos)
4. How it works
5. What we do (services)
6. Airports we serve
7. Choose your car (fleet)
8. Why customers book with us (stats + features)
9. Areas we serve
10. Common questions (FAQ)
11. Final call to action + footer, with a sticky Call/Book bar on mobile

## Files

- `index.html` — page markup
- `styles.css` — styles (no framework)
- `assets/img/` — images taken from the current website
- `preview/` — desktop and mobile screenshots
