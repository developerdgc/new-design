# Afaq Mines – Figma importer

Builds all 14 pages of the Afaq Mines website design in Figma as editable layers
(text, shapes, icons and photos), 1440 px wide, on a page called **Afaq Mines – Desktop**.

## Run it (Figma desktop app)

1. Download this `figma-plugin` folder (or the zip) to your computer.
2. Open the Figma file **Afaq Mines – Website Design** in the Figma **desktop** app.
3. Menu → **Plugins → Development → Import plugin from manifest…** and pick `manifest.json` from this folder.
4. Menu → **Plugins → Development → Afaq Mines Website Importer**.
5. Wait about a minute. When it finishes, a message shows how many layers were created.

Photos load from this GitHub repository, so the computer needs internet access.
Running it again adds another copy; delete the old frames first if you re-run.
