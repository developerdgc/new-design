# Digital Growth Catalyze — Portfolio Redesign

A dark + white redesign of [portfolio.digitalgrowthcatalyze.com](https://portfolio.digitalgrowthcatalyze.com/), using the colours and fonts of the main site [digitalgrowthcatalyze.com](https://digitalgrowthcatalyze.com/). All text, projects, links and reviews come from the current portfolio page.

**Open `index.html` in a browser to view it.** Screenshots are in `preview/`.

## Colours (from digitalgrowthcatalyze.com)

| Token | Value | Used for |
|---|---|---|
| Navy | `#062836` | Header, hero, dark sections |
| Navy deep | `#041D28` | Top bar, footer |
| Teal | `#116466` | Eyebrows, links on white |
| Cyan | `#1CDEE1` | Accent on dark, ticker strip |
| Orange | `#F6A440` | Main buttons, stars |
| Light | `#F2F7F8` | Light alternate section |

Fonts: **Unbounded** for headings, **Poppins** for body text (both used on the main site).

## Sections

| Section | Background |
|---|---|
| Top bar (phone, email, socials) | Navy deep |
| Header, sticky, white logo, orange "Contact Us" | Navy |
| Hero: headline, 2 buttons, 4 stats, website mockup | Navy with cyan glow |
| Portfolio: filters (All / Websites / UI/UX / Logos), 12 cards at a time + "Load More" | White |
| Customer Success Stories | Navy, teal gradient box |
| Services ticker | Cyan |
| About Us + Our Services | Light |
| Google reviews (5.0, 13 reviews) | Navy |
| Call to action | White |
| Footer | Navy deep |

Each website card shows a browser frame. On hover the full-page screenshot scrolls from top to bottom; the arrow button opens the live site.

## Notes

- Category typos from the live page are fixed (Guter → Gutter, Concreate → Concrete, Remolding → Remodeling).
- 13 projects have no live link on the current site, so their card has no arrow. Add the URL to show it.
- The page now has one H1 and a meta description (the live page has neither).
