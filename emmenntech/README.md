# EmmEnn Tech: website design

Approved design for the EmmEnn Tech site before it is built in WordPress Elementor.

- Preview: https://claude.ai/artifact/H9ZoFoKobrvvEUDeydd4o9
- Pages: Home, About Us, Our Services, Our Blog, Contact Us (flat menu, no dropdown).
- `src.html` is the page source. `data.js` holds services, reviews, FAQs and video data. `python3 build.py` inlines `assets/` and writes `emmenntech-site.html`.
- `logo/` has the new logo: lockups for dark and light backgrounds, icon PNG and SVG, app icon.

Colours: navy `#071233`, light `#EEF5FF`, brand gradient `#22C6E0` to `#1F6BE0`, accent gradient `#FFA53D` to `#FF5F3A`. Fonts: Urbanist (text), Space Grotesk (numbers), JetBrains Mono (labels).

The hero globe uses Three.js r128 from cdnjs. Testimonial names, case numbers and blog posts are samples to replace with real content.
